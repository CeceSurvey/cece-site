Android 安装

当前版本 v3.0.1 系统要求 Android 7.0 及以上
下载 APK 前往 Releases 页面

安装步骤

  1. 点击「下载 APK」，下载完成后打开文件。
  2. 系统提示「允许安装未知应用」时，为当前来源开启允许。
  3. 点击「安装」，完成后从桌面打开「测策」。
提示：若系统拦截安装，请在「设置 → 安全 → 安装未知应用」中允许文件管理器或浏览器安装。

iOS · 添加到主屏幕

「测策」是 PWA（渐进式 Web 应用），添加到主屏幕后即可全屏、离线使用。

方式 PWA 封装 浏览器 务必使用 Safari 环境要求 HTTPS

安装步骤

  1. 用 Safari 打开本站或主程序网址（iOS 上 Chrome 不支持）。
  2. 点击底部中间的 「分享」按钮（方框加向上箭头）。
  3. 在弹出菜单中滑动，点击 「添加到主屏幕」。
  4. 可自定义名称（默认「测策」），点击右上角 「添加」。
  5. 主屏幕出现「测策」图标，点开即全屏运行。

扫码直达 PWA 网址

注意：iOS 版为 PWA 封装，不是 App Store 应用；离线缓存需在 HTTPS 环境下首次访问后生效。

换设备 / 换平台？

数据不会自动云端同步。请在原设备上用「导出」生成 .cece.json 文件，再在新设备上「导入」即可无损迁移。
