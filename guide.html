通用操作

新建工作

打开「测策」后，点首页「新建工作」：先选工作类型（全站仪 / 水准 / 角度），再填工作名称（默认按日期时间生成）。水准测量可额外填起点已知高程与容许闭合差系数，之后点「创建并开始」进入工作区。

工作管理

「工作管理」支持：按名称搜索、按类型筛选、四种排序（最近修改 / 最早创建 / 名称 A→Z / 按类型）；右上角可「从文件导入工作」（单个或整包备份）与「批量管理」（多选后批量导出或删除）。每张工作卡片提供编辑 / 只读 / 重命名 / 删除。

自动保存与手动保存

停止输入约 0.5 秒自动落盘；顶栏「保存」按钮或 Ctrl / ⌘ + S 可立即保存。数据保存在本机浏览器存储中，不联网。

导出与导入

工作可导出为 .cece.json 文件备份；换设备或换平台时，在新设备上「导入」即可恢复。卸载软件或清理浏览器数据前，务必先导出备份。

全站仪测绘

表格与坐标方向

表格列为：排序 · 点号 · 棱镜高 · N(X) · E(Y) · H(Z) · 备注，数字格统一三位小数。录入坐标后，图上立即成点：N(X) 增大点向上、E(Y) 增大点向右。

说明：本模块是「坐标录入 + 成图」。水平角、距离到坐标的换算由全站仪或前序手工完成，程序不在此处做极坐标解算。

点号智能编号

新建工作时点号留空。在空点号格聚焦时，程序会向上找最近的数字点号，用浅灰色给出「+1」的预测值；直接点别处（不输入）就落成真实点号，输入了则以你输入的为准。

点位分类

备注命中关键词时自动归类（默认四类：碎部点 / 控制点 / 测站点 / 辅助点），点号颜色随之变化。图上「编辑点」可手动改某一点类型；分类与关键词可在「关于 → 程序设置」自定义。

连线与排序

图上点选多个点可连成折线，支持改颜色 / 删除。按住首列滑块上下拖动可调整点位顺序。

水准测量

记录表怎么填

记录表每测站占两行（后视点行 / 前视点行）。在对应位置填入 后视读数 a 与 前视读数 b，以及各自的视距。高差与高程由程序自动计算。

计算逻辑

项公式说明
测段高差h = a − b后视减前视
各点高程H = H起 + Σh逐段累计
检核式Σa − Σb = Σh = H终 − H始三项应相等
闭合差f_h = Σh实测 − (H终 − H始)已知单位 m
改正数v_i = −f_h × (L_i / ΣL)按距离比例反号分配；缺距离按测段数均分；单位 mm
改正后高差h' = h + v / 1000再由改正后高差累计得改正后高程
容许闭合差f_h允 = c√Lc 默认 40，L 为路线长（km）；超限标红

闭合 / 附合自动识别

标题栏「H终」留空或等于起点高程 → 按闭合水准计算；填不同值 → 按附合水准计算。

成果表

成果表列为：测段编号 · 点号 · 测段距离 · 观测高差 · 高差改正值(mm) · 改正后高差 · 高程 H · 备注，底部给出 Σ 与闭合差 f_h、容许闭合差 f_h允。

角度测量

测回法怎么填

每个测回录入 4 个读数：A 盘左、B 盘左、A 盘右、B 盘右。读数支持多种度分秒格式，如 45°30′30″、45 30 30、45:30:30，程序统一解析。

计算逻辑

项公式说明
半测回角值β左 = B盘左 − A盘左
β右 = B盘右 − A盘右		归化到 [0°, 360°)
一测回角值β = (β左 + β右) / 2圆周平均，避免 359°/1° 跨界出错
半测回较差β左 − β右限差 40″
各测回平均角值circularMean(β₁ … βₙ)按测站分组取圆周平均
测回间较差βᵢ − 站平均限差 24″

限差判定

程序自动统计超限的测回并标出，帮你快速发现超限的观测结果。

数据分析

图表与指标

「数据分析」选一份工作后，可查看概览指标与三类图表：全站仪「平面坐标图」、水准「里程—高程图」、角度「角值柱状图」。

导出

支持三种导出：导出图片（PNG 带标题与图注）、导出 CSV（可用 Excel / WPS 打开）、智能纸图（按纸张尺寸选比例尺，附「纸上量取」表，仅全站仪 / 水准）。
